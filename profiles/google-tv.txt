# The setup wizard is the important one: com.google.android.tungsten.setupwraith claims HOME
# with priority=1.  cmd package set-home-activity reports "Success" and the home button
# STILL opens the setup wizard, because the wizard outranks the launcher and Android drops
# the HOME preference whenever the set of HOME apps changes.
# Disable it BEFORE setting the home app, and verify afterwards.
